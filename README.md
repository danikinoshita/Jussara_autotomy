

# Overview

This repository contains the data and R scripts used in the study:

**Kinoshita, D. A., W. C. A. Bezerra, T. M. Del Corso, and G. Machado.
2026. Going Out on a Limb: Appendage Length and Function Shape Leg Loss
Without Evidence of Autotomy Modulation. *Ethology* 1–9.
https://doi.org/10.1111/eth.70118.**.

The study analyses patterns of leg autotomy in the harvestman *Jussara*
sp. (Sclerosomatidae) by quantifying autotomy frequency across leg types
and years. Monte Carlo randomizations are then used to test whether (1)
the loss of one leg reduces the probability of losing its homologous
counterpart, and (2) the loss of one ambulatory leg reduces the
probability of losing another ambulatory leg on the same side of the
body.

This repository includes the original and processed datasets, and fully
annotated analysis scripts used to generate all results and figures
presented in the manuscript. The materials are provided to ensure
transparency, reproducibility, and long-term accessibility of the
analyses.

# Repository structure

The repository is organized into the following folders and files:

## Data

### Raw data

Contains the raw datasets exported directly from field notebooks and
early spreadsheets from four sampling events conducted at Intervales
State Park (24°14′S, 48°40′W; 800 m a.s.l.): March 2002 (n = 380),
October 2009 (n = 485), March 2011 (n = 208), and February 2012 (n =
332). All surveys were conducted during the warm and wet season, when
the species is most abundant at the study site. These files have
undergone only minimal manual corrections to address evident field
recording errors during data transcription, along with basic formatting
adjustments to ensure compatibility with R. No systematic cleaning or
analytical processing has been applied.

*Note: Ambulatory legs correspond to leg pairs I, III, and IV. Leg pair
II is specialized for sensory functions and was therefore excluded from
analyses involving ambulatory legs.*

- `main_raw` - A 1405 x 13 data frame containing autotomy information
  for all individuals included in this study.
  - `id` - Individual identification number.
  - `r1` to `r4` - Autotomy status of right legs I to IV (`0` = intact,
    `1` = autotomized).
  - `l1` to `l4` - Autotomy status of left legs I to IV (`0` = intact,
    `1` = autotomized).
  - `right` - Number of autotomized right ambulatory legs (`0` to `3`).
  - `left` - Number of autotomized left ambulatory legs (`0` to `3`).
  - `total` - Total number of autotomized legs.
  - `population` - Sampling event, identified by collector initials
    (March 2002 = `TG`, October 2009 = `MC`, March 2011 = `GE`, and
    February 2012 = `GP`).
- `sex_raw` - A 147 × 8 data frame containing autotomy information for
  147 individuals whose sex was determined during the 2002 sampling
  event.
  - `Right` and `Left` - Total number of autotomized ambulatory legs on
    the right and left sides of the body, respectively (`0` to `3`).
  - `Leg.I` to `Leg IV` - Autotomy status of leg pairs I–IV (`0` =
    intact, `1` = autotomized).
  - `Male` and `Female` - Sex indicator variables (`1` = yes, `0` = no).
- `leg_length_raw` - A 10 × 5 data frame containing leg-length
  measurements for 10 individuals sampled during the 2002 sampling
  event.
  - `Individual` - Individual identification number (not necessarily the
    same as in the `main_raw` data frame).
  - `Leg.I` to `Leg.IV` - Leg length (mm), measured from the base of the
    femur to the tip of the tarsus.

### Processed data

Processed objects ready for analysis, including filtered records,
recoded variables, and intermediate results generated by previous steps,
which are used as inputs for subsequent analyses.

- `main_data` - A 11240 x 6 data frame containing the same information
  as `main_raw`, but arranged in long format. Generated by
  `scripts/01_data_curation.qmd`.

  - `id` - Individual identification number (integer).
  - `leg_id` - Leg identifier (factor). Levels `r1` to `r4` correspond
    to right legs I–IV, respectively, and levels `l1` to `l4` correspond
    to left legs I–IV, respectively.
  - `leg` - Leg type (factor; levels `1`–`4`).
  - `side` - Body side of the leg (factor; `right` or `left`).
  - `autotomy` - Autotomy status of the corresponding leg (integer; `0`
    = intact, `1` = autotomized).
  - `population` - Sampling event, coded by year (factor; `2002`,
    `2009`, `2011`, and `2012`).

- `sex_data` - A 588 x 4 data frame containing the same information as
  `sex_raw`, but arranged in long format. Generated by
  `scripts/01_data_curation.qmd`.

  - `id` - Individual identification number (integer, not necessarily
    the same as in the `main_data` data frame).
  - `sex` - Individual sex (factor, `F` or `M`).
  - `leg_id` - Leg-pair identifier (character). Unlike the `leg_id`
    column in `main_data`, this variable does not contain information on
    body side.
  - `autotomy` - Autotomy status of the corresponding leg pair (numeric;
    `0` = neither leg autotomized, `1` = one leg autotomized, `2` = both
    legs autotomized).

- `leg_length_data` - A 40 x 3 data frame containing the same
  information as `leg_length_raw`, but arranged in long format.
  Generated by `scripts/01_data_curation.qmd`.

  - `id` - Individual identification number (integer, not necessarily
    the same as in the `main_data` data frame).
  - `leg_id` - Right leg identifier (character).
  - `length` - Length of the corresponding right leg (numeric, mm).

- `marginal_autotomy_probabilities` - A 16 × 7 data frame containing
  estimated marginal means (EMMs) from the final binomial GLMM fitted
  using `main_data`, with `leg` and `population` as fixed effects and
  `id` as a random effect, predicting `autotomy`. Generated by
  `scripts/02_descriptive_analyses.qmd`.

  - `leg` - Leg type (factor; levels `1` to `4`).
  - `population` - Sampling event, coded by year (factor; `2002`,
    `2009`, `2011`, and `2012`).
  - `prob` - Estimated marginal probability of autotomy
    (back-transformed to response scale).
  - `SE` - Standard error of the estimated marginal probability (on the
    response scale).
  - `df` - Degrees of freedom (Inf, asymptotic).
  - `asymp.LCL` - Asymptotic lower confidence limit (95% CI, response
    scale).
  - `asymp.UCL` - Asymptotic upper confidence limit (95% CI, response
    scale).

- `sim.leg1`, `sim.leg2`, `sim.leg3`, `sim.leg4` - Vectors containing
  simulated values (length = 10000) of the null test statistic for the
  co-occurrence of autotomy between homologous leg pairs I–IV,
  respectively. Each value represents the number of individuals in which
  both the right and left leg of a given pair were simultaneously
  autotomized under the null model of random autotomy allocation within
  years. Generated by `scripts/03_hypothesis_testing.qmd`.

- `sim.side` - A vector containing simulated values (length = 10000) of
  the null test statistic for within-side clustering of autotomy. Each
  value represents the total number of individuals with simultaneous
  autotomy of any two ambulatory legs on the same body side (right or
  left) under the null model of random autotomy allocation within years.
  Generated by `scripts/03_hypothesis_testing.qmd`.

- `simulation_results` - A 5 × 5 data frame summarizing Monte Carlo null
  model simulations and their comparison with observed test statistics
  for each hypothesis tested (leg pairs I–IV and within-side
  clustering).

  - `leg` - Test category (factor; `leg1`–`leg4` correspond to
    homologous leg-pair co-occurrence tests for legs I–IV, respectively,
    and `side` corresponds to within-side clustering of autotomy).
  - `mean` - Mean value of the simulated null distribution for each test
    statistic.
  - `Q2.5` - Lower bound of the 95% Monte Carlo confidence interval
    (2.5% quantile of the null distribution).
  - `Q97.5` - Upper bound of the 95% Monte Carlo confidence interval
    (97.5% quantile of the null distribution).
  - `p_value` - Monte Carlo p-value computed as the proportion of
    simulated values less than or equal to the observed test statistic,
    using a +1 correction to avoid zero probabilities.

## Scripts

Each analysis script is provided as a Quarto document (`.qmd`) together
with a rendered `.html` companion. The `.qmd` files contain the full,
executable analysis code and should be run in the order listed below;
the `.html` files are reader-friendly summaries that can be opened in
any web browser without running R.

- `01_data_curation.qmd` - Initial curation, reorganization, and
  formatting of the raw data prior to analysis.

- `01_data_curation.html` - A reader-friendly version of
  `01_data_curation.qmd`, designed for quick reference, presenting the
  main data-curation steps without detailed code-level explanations.

- `02_descriptive_analyses.qmd` - Pre-hypothesis testing analyses used
  to evaluate potential differences in autotomy incidence among leg
  types, body sides, and populations, in order to determine which
  structure should be retained in the permutation analyses. This script
  also tests whether different leg types differ in overall length, and
  whether autotomy probability varies with sex and leg identity.

- `02_descriptive_analyses.html` - A reader-friendly version of
  `02_descriptive_analyses.qmd`, designed for quick reference,
  presenting the main analyses and findings without detailed code-level
  explanations.

- `03_hypothesis_testing.qmd` - Final hypothesis testing script in which
  a null-model approach is used to test two hypotheses: (1) that the
  loss of one leg reduces the probability of losing its homologous
  counterpart within the same leg pair; and (2) that the loss of one
  ambulatory leg reduces the probability of losing another ambulatory
  leg on the same body side.

- `03_hypothesis_testing.html` - A reader-friendly version of
  `03_hypothesis_testing.qmd`, designed for quick reference, presenting
  the main hypotheses, analytical approach, and findings without
  detailed code-level explanations.

## Project and environment files (root directory)

- `README.md` - This file. It is the single README of the data package
  and describes all files and folders.

- `Jussara_autotomy.Rproj` - RStudio project file. Opening it in RStudio
  sets the working directory to the repository root, so that all
  relative paths used in the scripts resolve correctly. It contains no
  data or analysis code.

- `references.bib` - BibTeX file containing the references used in the
  scripts. It is read automatically when the script is rendered and does
  not need to be edited to reproduce the analyses.

- `renv.lock` - {renv} lockfile recording the R version and the version
  and source of every R package used in the analyses. It is used by
  `renv::restore()` to rebuild the same computational environment (see
  “How to reproduce the results”).

- `renv/` - Project-specific {renv} folder. It contains the activation
  script (`renv/activate.R`) and the {renv} settings
  (`renv/settings.json`). The project-local package library is not
  included in this repository and is rebuilt from `renv.lock`.

- `.Rprofile` - Startup file that automatically activates {renv} when
  the project is opened in R or RStudio. It contains no analysis code.

# How to reproduce the results

These steps fully restore the computational environment and reproduce
all analyses, figures, and tables reported in the manuscript.

## Prerequisites

- R (\>= 4.5.0) installed.

## Step-by-Step

1.  Clone this repository:

*Note: currently ommited for anonimization purposes*.

2.  Open the R project file (`Jussara_autotomy.Rproj`) in RStudio.

3.  Restore the package environment using {renv}:

``` r
install.packages("renv")       # if not already installed
renv::restore()                # installs packages from renv.lock
```

4.  Run the analysis scripts in order:
    1.  `scripts/01_data_curation.qmd`
    2.  `scripts/02_descriptive_analyses.qmd`
    3.  `scripts/03_hypothesis_testing.qmd`
